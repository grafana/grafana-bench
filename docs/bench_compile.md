## bench compile

bench test compiler

### Synopsis

bench compile subcommand retrieves and builds a test suite from a given source location

```
bench compile [flags]
```

### Examples

```

bench compile --target-dir work/tests  \
    --test-suite-repo git@github.com:grafana/grafana-api-tests \
    --test-suite-revision main

```

### Options

```
  -h, --help                         help for compile
      --target-dir string            directory for checking the test into.
                                     If exists, it is assumed the test suite repository is already checked out in it.
      --test-suite-repo string       repository to grab test suite from
      --test-suite-revision string   test suite revision to compile.
                                     Can make reference to a branch (local or remote), a tag or a specific commit hash
                                     If not provided and the repo is already checked out in the base dir, the current branch is compiled.
                                     Otherwise the main branch from the remote repository is compiled
```
